# SepticHow

Next.js 16 / React 19 / TypeScript / Tailwind 4. Portable Debian VPS build.

## Run

Requires Node.js 20.9+ (Node 22 LTS recommended).

```bash
npm ci
npm run dev
```

## Verify

```bash
npm run typecheck
npm test
npm run build
```

Includes a tank-flow planner, pumping frequency estimator, pumping cost range and quote auditor, tank-volume calculator, drain-field planning calculator, riser payback calculator, symptom troubleshooter, browser-local schedule, guide library, and trust pages. Tool routes emit free-use SoftwareApplication and FAQPage structured data. Sitemap and robots routes are generated by Next.js metadata routes.

Tank sizing has no universal 50-state bedroom-to-capacity rule. The tank planner provides household-flow arithmetic and the Minnesota example only; state code reference shells stay out of the index until their rules are researched and verified. Pumping intervals are lookup estimates and not legal or inspection advice. Cost estimates are broad US planning ranges, not regional quotes. Drain-field sizing requires a soil loading rate supplied by a site evaluator or permit and does not infer one from percolation time. Verify dimensions against the exact tank manufacturer's drawing.

## Deploy

See DEPLOY.md. No analytics property IDs, Search Console verification token, advertising or contact integration has been fabricated. Configure these before public launch. Submit the sitemap in Search Console after deployment.

## Structure

- src/lib/calculations.ts — shared pure functions
- src/lib/sources.ts — source provenance and origin
- src/lib/content.ts — structured page and tool data
- src/components/Calculator.tsx — browser interaction
- src/app — server-rendered, statically generated routes

Saved schedules use localStorage key septichow-schedule-v1. They are not uploaded or synchronized. All input changes clear stale results.
